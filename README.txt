АРТЕМ-ТОКАРЬ — ОБНОВЛЁННЫЙ САЙТ

1. ЧТО ОТКРЫВАТЬ
Распакуйте ВЕСЬ архив. index.html — основной сайт, config.js — отдельные настройки.
Оформление, шрифт и основной код встроены в index.html: прежняя проблема
«голого HTML» не повторяется даже при недоступности соседних стилей/фото.
На компьютере index.html можно открыть прямо браузером.
Для редактирования и публикации сохраняйте структуру папок.

На телефоне для быстрого просмотра откройте offline-preview.html обычным браузером
из приложения «Файлы»/«Мои файлы». Это ОДИН самостоятельный файл с копией текущего
конфига. Соседние файлы ему не нужны. Если внутренний просмотрщик Telegram не
умеет открывать HTML, сохраните файл в «Загрузки» и выберите браузер.
Некоторые мобильные просмотрщики не дают index.html читать соседний config.js.
Тогда дизайн сохранится, но настройки останутся заглушками; используйте preview
или размещение сайта на хостинге. Сайт пока НЕ опубликован, публичной ссылки нет.

2. КОНТАКТЫ — ТОЛЬКО CONFIG.JS
phoneDisplay / phoneLink — основной номер для показа и звонка (+ и цифры).
telegramUrl — собственная HTTPS-ссылка Telegram (t.me или telegram.me).
maxUrl — собственная HTTPS-ссылка из «Поделиться» MAX (max.ru или web.max.ru).
Не подставляйте случайную ссылку: пустое значение отключает кнопку.
footerPhoneDisplay / footerPhoneLink — отдельный нижний телефон;
если пустые, используется основной номер.
footerEmail — почта внизу. Все значения пока пустые, контакты не выдуманы.
performer — фактическое имя/название, статус, адрес, регистрация, ИНН, дни работы.
Контакты/реквизиты выводятся безопасно как текст, не как HTML.
Конфиг публичный: никогда не храните здесь пароли, токены, паспортные данные.

После правок config.js ОБЫЧНЫЙ index.html получает настройки при обновлении
страницы, пересборка ему НЕ нужна. Для обновления однофайлового offline-preview.html
выполните python3 build.py — он создаст свежую копию с текущим конфигом.
Если Python нет, для публикации достаточно index.html + config.js + photos/.

3. КАК ДОБАВИТЬ ФОТО
Все прежние фото удалены. Сейчас только одна карусель с тремя пустыми слайдами.
Скопируйте свои изображения в photos/. Имена файлов — латиница, без пробелов.
В массиве photos файла config.js заполните src, title и alt, например:
{ src: "photos/shaft-01.jpg", title: "Вал", alt: "Стальной вал с обработанной поверхностью" }
Можно добавлять и удалять строки. Пустой src оставляет заглушку.
Поддерживаются JPG/JPEG/PNG/WebP/AVIF. Пути только внутри photos/.
Фотографии показываются целиком без обрезки. При ошибке пути появится понятная
заглушка, а не сломанное изображение. Карусель: стрелки, точки, клавиши ←/→,
свайп на телефоне. Автопрокрутки нет.
После добавления фото обновите страницу; для preview запустите build.py,
который встроит фото внутрь однофайловой версии. Затем снова передайте preview.
Указывайте только свои фото или материалы с достаточными правами на публикацию.

4. ШРИФТ И АНИМАЦИИ
Unbounded (жирные начертания 750–850), кириллица, свободная лицензия SIL OFL 1.1.
Платная лицензия не нужна. Это не «совсем без лицензии»: условия OFL сохранены.
assets/fonts/Unbounded.ttf и OFL.txt включены; шрифт встроен в обе HTML-версии,
нет обращений к Google Fonts/CDN. Источник: https://github.com/google/fonts/tree/main/ofl/unbounded
Вход блоков при прокрутке, мягкие hover-эффекты, переходы карусели,
медленно вращающееся техническое кольцо. Учитывается prefers-reduced-motion:
при запросе пользователя анимации отключаются, контент остаётся видимым.

5. ИСХОДНИКИ И СБОРКА
src/template.html — структура/тексты;
src/styles.css — оформление/анимации;
src/script.js — контакты, карусель, анимации;
config.js — контакты, реквизиты, список фото;
build.py — сборка index.html и offline-preview.html без дополнительных пакетов.
После правки src/* или замены файла шрифта запустите python3 build.py.
Для хостинга загрузите index.html, config.js и папку photos. Не размещайте старые
версии сайта со снимками, которые были удалены по вашему запросу.
